Local, not uploaded

A vision model runs on your machine and describes each file. Nothing leaves the computer, so private folders stay private.

Nothing renames itself

You see the suggested names, edit any of them, validate, and dry-run first. Files change only after you confirm the plan.

Every rename is reversible

Each operation is journalled, so one click undoes the last batch — including swaps, cycles and case-only changes.

Images and short videos

JPEG, PNG and WebP, plus MP4, MOV, MKV, WebM and AVI clips: frames are sampled and the clearest ones describe the file.

Before you install — read this

FileSight's analysis engine is a Python program, and the desktop app runs it. The installer does not yet bundle Python, so the app needs Python 3.11 or newer plus the FileSight core installed from the repository. The README has the two commands.

Video support needs FFmpeg, and that part is one click: the app offers to download it into its own folder, with no PATH editing and nothing else on the system touched.

Updates are built in — an installed copy checks for a new release and offers to install it.
